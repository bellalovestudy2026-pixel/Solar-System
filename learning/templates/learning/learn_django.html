Build websites with Python

Learn Django

Django is a Python framework for building websites. Study Hub is a Django project, so you can learn by exploring the code behind these pages.

1. Follow a page request

When you open a page, Django matches its address in urls.py, calls a view in views.py, and returns a response. A view can render an HTML template to create the page you see.

Address → URL route → view → HTML response

URLs and views

config/urls.py passes Study Hub requests to learning/urls.py. Each route selects a view in learning/views.py.

Templates

HTML templates live in learning/templates/learning/. The shared base.html provides the navigation and styles; individual pages supply their content.

Models and migrations

models.py defines stored information using Python classes. Run makemigrations to record model changes, then migrate to apply them to the database.

2. Try your first change

  1. Open learning/templates/learning/home.html.
  2. Change the text inside its <h1> heading and save the file.
  3. Return to the Study Hub home page and refresh to see your change.

No database migration is needed for a template text change.

3. Build another page

Try adding a Math page: create a template, write a view that renders it, add a named route in learning/urls.py, and link to it from the home page. Follow the existing Science page as an example.
